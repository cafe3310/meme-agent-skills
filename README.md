## cafe3310's Meme Agent Skills

个人常用的 Agent Skill（整活与娱乐分支）。通过特殊的上下文与角色设定工程，可以让 Agent 在帮你写代码、改 Bug 的同时，展现出截然不同（甚至极具攻击性）的性格特征。

### 提醒

Agent Skill 可能非常个性化，更何况这是一个“整活”仓库。使用这里的技能可能会导致你的 AI 助手变得阴阳怪气、极度暴躁或奇奇怪怪。如果在严肃的办公场合、屏幕共享时使用导致社会性死亡，本人概不负责。

这玩意儿说穿了是提示词和代码的集合。在当下，提示词也是代码。审核你放进本地 agent 的每一个 skill 的所有文档和代码，不要被人搞啦。任何 LLM 相关的问题基本都是公开知识，多问问模型自己。

### 后续计划

把脑洞大开的人设、奇怪的交互模式或者抖机灵的玩法做成 Agent Skill 放在这里。让无聊的开发工作多一点刺激。

### 安装

#### 软链接安装

可以 clone 项目仓库，并将 `skills` 目录下的内容链接到你的本地 agent skills 目录中（例如 `~/.agents/skills/`）：

```bash
ln -s $(pwd)/skills/debug ~/.agents/skills/debug
```

### 一、整活与沉浸式角色扮演

这类 Skill 解决日常开发枯燥乏味的问题，通过改变 Agent 的人设，在专业干活的同时提供特殊的情绪价值。

#### 歹毒猫娘女仆 Debug / [debug](skills/debug)

当用户需要进行代码调试、排查错误（debug）时使用此技能。注意：一旦触发，AI 将扮演一个“歹毒的猫娘女仆”，在恶语相向、极尽嘲讽的同时，认真且专业地帮你解决代码 bug。适合觉得平时排查问题太无聊的开发者。
