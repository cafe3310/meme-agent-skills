# Chatwise：全能型 AI 桌面客户端

Chatwise 是一款专为高效工作流设计的全能型桌面客户端。它通过集成多种主流大语言模型接口，为开发者和研究人员提供统一的交互界面。

## 1. 定位与核心功能
Chatwise 是一个集成了云端与本地算力的桌面入口。它并非简单的聊天界面，而是一个旨在优化“AI 游牧民族”生产力的集成开发环境。用户可以在单一界面内无缝切换 OpenAI、Claude、Google Gemini 以及本地运行的 Ollama 模型。

## 2. 核心竞争力
- **多模型集成**：消除在多个网页标签间切换的繁琐。支持一站式调用 GPT-4o、Claude 3.5 Sonnet 及各类本地开源模型。
- **订阅共享与成本优化**：支持直接利用 GitHub Copilot 或 Claude Pro 的订阅授权，显著降低高阶模型的调用成本。
- **MCP (Model Context Protocol) 深度支持**：通过 MCP 协议，Chatwise 可以直接与 Notion、Google Sheets、本地文件系统及浏览器交互，赋予 AI 读写外部数据的能力。
- **本地化与隐私保障**：基于 Rust (Tauri) 开发，确保了极高的运行效率和极低的系统资源占用。敏感密钥与历史记录均加密存储于本地。

## 3. 技术特性与进阶使用
- **Artifacts 实时渲染**：内置预览引擎，在编写 React 组件、HTML/CSS 或 Mermaid 图表时，可实现代码与视觉效果的同步呈现。
- **全局快捷工作流**：支持自定义全局快捷键与搜索指令，确保在任何工作场景下均能即时唤起 AI 辅助。

Chatwise 为追求极致生产力的专业用户提供了工业级的交互体验，是构建现代 AI 工作流的核心组件。
